# Log 038 — Collection GUI for both methods (leader arm and PICO) (2026-11-01)

## Why (Suraj: "instead of the terminal … a good GUI … both methods, leader arm and PICO", not in the Dream-Lab page)
Two terminals, keyboard focus on the recorder, scrolling output and a manual stop order caused mistakes today
(keys to the wrong window, esc while squeezing, dry run started without a squeeze, pasted commands breaking).

## Learned from the Dream-Lab-OpenArm Collect tab (`october 23/workspace/collect.py`, read only, not changed)
- Run the recorder script **unchanged** in a pseudo-terminal and type its keys (→ ← a Esc): the data is saved
  exactly as from the terminal. lerobot puts its terminal in cbreak mode, so single keys arrive at once.
- The page only shows what the scripts print; refuse to start when another teleop runs; keep notes per run.

## Choice
- **NiceGUI** (Python, FastAPI + Vue/Quasar; MIT, ~16k GitHub stars, active 2026) instead of viser (the Collect
  tab's 3D UI): this page is buttons, status and logs, no 3D. Added to the setup line (`nicegui>=2,<3`, 2.24.2).
- Separate page in this repo; port 8090 on 127.0.0.1 only.

## Code
- `pico_teleop/gui/session.py`: `Options`; `teleop_command` (PICO sender with `--hz 60 --max-joint-acc-dps2 300`,
  `--orientation`, `--premove-forward-cm`, JSONL log; or `scripts/leader_sender.sh <side>`); `recorder_command`
  (`pilot_record.sh <method> <n>` with SIDE / OPERATOR / TASK / EPISODE_TIME_S); `PtyChild` (pty, line buffer, keys,
  Ctrl-C to the process group); `SenderMonitor` (tails the sender JSONL: state, link, wall, wall time, input rate,
  facing, LOCKED, events); `other_senders` (pgrep); `go_no_go_today` (today's runbook column); `CollectionSession`
  (order ① teleop → ② spotter power → ③ recorder; refusals listed in the README; per-episode notes + wall time).
- `pico_teleop/gui/app.py`: the page (Setup / Episodes, Run / Live status, logs), 0.5 s refresh.
- `scripts/gui.sh`; `scripts/leader_sender.sh left|right`; `scripts/pilot_record.sh` takes `SIDE` (right wrist D405
  352122273417).
- Tests `tests/test_gui_session.py` (9, no robot): commands for both methods, refusal with another sender, the order,
  the → key reaching a cbreak recorder, wrong sha, Esc refused while ENGAGED, leader stop needs "held", monitor
  parsing, go/no-go parsing, notes. Suite **130 passed**. Page served and checked in a browser (screenshot
  `docs/img/collection-gui.png`).

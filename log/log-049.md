## Choice: reuse the follower receiver on the leader's CAN (no lerobot change)
- Options: (a) add a position-hold mode to lerobot `openarm_leader.py` (changes the leader for everyone → PR + Kento);
  (b) **run the existing follower receiver (`lerobot-teleoperate --robot.type=openarm_follower` +
  `openarm_leader_remote`) with `--robot.port=can_lead_*`**. Chosen (b): no shared code changes.
- Why it is valid: leader and follower have the same motor table (`config_openarm_leader.py` vs
  `config_openarm_follower.py`, identical) and the same calibration format (ids, drive_mode, ranges equal; only
  homing offsets differ). The follower class only checks that a calibration file exists (`damiao.py:1132`
  `is_calibrated = bool(self.calibration)`), so a copy of the leader's calibration under the follower path is used as
  is, with no re-calibration motion.
- Leader in plain v5 earlier today: joints 1-6 matched the follower's pose; only joint_7 fell (gravity-only mode,
  log-048), so the leader's logical angles agree with the follower's.

# Log 015 — Wrist rotation (orientation control), offline + replay (2026-10-31)

Requested by the operators after session 3 (log-014). **Off by default** (`--orientation` to enable)
until it passes a headset dry run and a supervised arm session.

## Design (options and choice)
| Question | Chosen | Why |
|---|---|---|
| absolute vs relative | **relative to the engage pose** (like position) | no jump at engage; operator's grip on the controller does not matter |
| mapping | R_des = (R_hand · R_hand,anchorᵀ) · R_tcp,anchor, all in the robot frame (`controller_in_robot` R·M·Rᵀ; OpenXR is right-handed, log-008) | the gripper turns about the same world axis by the same angle as the hand |
| IK | 6-DOF damped LS, orientation weight 0.3 m/rad, same seed/step bound | position stays primary; orientation reaches 3° or FAULT |
| limits | target rotation ≤ 90°/s; FAULT on a hand rotation step > 45° in one update; existing joint/step/posture/lag limits unchanged | catch-up jumps and unreachable wrist angles stop instead of moving |

## Where
- `kinematics.py` `ArmKinematics.jac6()`, `solve_pose()` → (IKResult, rotation error).
- `controller.py` `TeleopConfig.orientation, max_rot_speed_dps (90), ik_rot_tol_deg (3), ik_rot_weight
  (0.3), max_hand_rot_step_deg (45)`; `HandInput.rot`; `PicoAdapter` passes the robot-frame rotation;
  `ArmTeleop.step()` anchors `anchor_hand_rot` / `anchor_tcp_rot`, rate-limits `R_target`, uses
  `solve_pose` when orientation is on.
- `sender.py` `--orientation`; the status line adds `rot x/y/z deg` (gripper rotation since engage).
- README Controls + message table.

## Evidence
- `tests/test_orientation.py` (11): pose IK round trip; both arms × three axes: hand +20° → gripper
  +20° about the same axis (±1.5°) with the position held; off = rotation ignored; 40° hand snap is
  rate-limited (≤ 90°/s) and every packet validates; 60° one-update rotation jump → FAULT; turning
  past the wrist range → FAULT. Full suite **83 passed**.
- Replay of session 3's real input (Kota-san), dry: orientation ON → 4 engages, gripper follows up to
  60° of hand rotation, max joint step 0.90°/cycle, no rotation-jump/unreachable FAULTs; one extra
  posture FAULT (joint_5 61°) vs orientation off.

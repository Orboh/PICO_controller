## Fixes (Suraj's decision), `controller.py`
| Fix | Where | Behaviour |
|---|---|---|
| **FAULT lockout** | `_fault()`, `fault_lock_count=2`, `fault_lock_window_s=30` | the same FAULT (key = message head) twice within 30 s → `LOCKED`: engaging refused until the sender restarts |
| **session drift limit** | `step()`: engage refused if any joint > `max_session_drift_deg` (60) from the session start; FAULT if the IK answer would exceed it | no slow creep into joint limits over many squeezes |
| **softer orientation** | `step()` orientation branch: if position+rotation is unreachable → position-only solve; rotation error ≤ `rot_fault_deg` (20°) is accepted (target = best reachable rotation); FAULT only above 20° | follows the position instead of FAULTing when the exact wrist angle is out of reach |
